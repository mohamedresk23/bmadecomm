المصدر: [PRD v2](../../prds/prd-bmadecomm-v2-2026-10-05/prd.md). المهمة توثيق UX فقط، دون implementation code أو تعديل المتطلبات.

| [DESIGN.md](DESIGN.md) | قيود العرض والمكونات وتركيب الصفحات؛ الهوية والألوان والخطوط غير محددة بطلب المستخدم. |

قواعد الاستخدام: لا تتحول P1/P2 إلى شاشات إطلاق، ولا تُعد A-01–A-11 أو OQ-01–OQ-08 معتمدة بمجرد توثيق الرحلة. قيم الألوان والخطوط والأبعاد غير المحددة لا تُملأ بمكتبة افتراضية. على المعمارية لاحقًا تثبيت API والمزودين والحقول غير المحددة في المصدر، دون تغيير قرارات المنتج بصمت.

حالة الوثائق draft بسبب قرارات PRD المفتوحة والهوية المؤجلة. اكتمال تعريف UX في نطاق هذه الجولة لا يمثل موافقة إطلاق أو تحقق WCAG من تطبيق منفذ.
